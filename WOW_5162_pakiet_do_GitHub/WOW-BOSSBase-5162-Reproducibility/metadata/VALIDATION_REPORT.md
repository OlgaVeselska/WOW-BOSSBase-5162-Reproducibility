# Pre-release validation report — 2026-10-29

## Checks completed

- Five original Python scripts are included, unmodified.
- Python syntax compilation passed for all five scripts (`python -m compileall -q scripts`).
- `results/WOW_capacity_audit.csv` contains the 10,000-image dataset audit.
- `results/WOW_5162_analiza_ladunku.csv` contains 16 modeled payload settings (decimal commas; semicolon delimiter).
- BOSSBase source images and WOW binary are intentionally not redistributed.

## Distinct numerical procedures: do not conflate

- At requested payload 0.20 bpp, the **CSV modeled-payload analysis** reports `lambda=4.862298064178816e-10`, modeled entropy payload `0.19999971058713403` bpp, and `liczba_iteracji=200`.
- A **separate C++-logic diagnostic**, reported in the accompanying research session, gave `lambda=4.856701707467437e-10`, `alpha_out=0.20055906474590302`, and 40 iterations. This value is not regenerated by the archived CSV; original execution evidence and a validated reproduction log are still needed before claiming bit-for-bit agreement.
- The `max_bpp_hard` metric is a *combinatorial hard-exclusion proxy*, not actual WOW payload capacity.

## Remaining blockers for full reproducibility

1. The original cover `data/raw/BOSSBase_1.01/cover/5162.pgm` and stego `data/stego/WOW/0.2/5162.pgm` are absent. The main diagnostic cannot run end-to-end from this ZIP alone.
2. The original image-5162 WOW invocation, seed, executable build and STC/simulation mode have not been verified from the original generation log. The `generate_stego.py` script currently requests `-h 0` (simulation) and a deterministic seed, but that alone does not prove it created the archived stego file.
3. Dependencies and exact versions are not pinned; the Windows-specific diagnostic path strings must be used in a compatible project directory or adapted.
4. The included third-party code excerpts and numeric derived outputs need a final redistribution/rights review before public release.
5. An independent clean-environment run with legally obtained BOSSBase data remains to be performed.

**Release recommendation:** keep this archive as a reviewed draft. Do not assert complete reproducibility or a public repository URL yet.
